# Knowledge 資料填寫說明

請將可供 Bot 查詢的公開資料放在此資料夾，支援 `.md` 與 `.txt`。

建議依主題分資料夾，例如：

```text
knowledge/
├── project/
│   └── architecture.md
└── minecraft/
    └── reference.txt
```

原始檔案是 Knowledge 的 Source of Truth。Bot 先以可重建的 FTS/向量索引找候選檔案與段落，再重新讀取原始檔驗證內容；若檔案已修改或刪除，舊索引不會被拿來回答。修改資料後請由 Owner 執行 `$ai index` 更新索引。

不要放入 API key、Token、密碼、私人對話或不應提供給使用者的資料。
